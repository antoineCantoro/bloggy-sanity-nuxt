# Bloggy - Nuxt x Sanity Template

## Requirement
Sanity project
Pnpm
node v26

## Install

## Create .env
## Install with pnpm install
## Run local servers (studio & web) : 
```pnpm -r --parallel dev```

## Structure
```
├── studio/   Sanity Studio (standalone, port 3333)
└── web/      Nuxt.js app (port 3000)
```
